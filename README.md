# Parcel Tracker

A small command-line tool for looking up and updating parcel statuses.

## How to run

1. Install Python 3.
2. Open a terminal in this folder.
3. Run: python3 main.py

## What it does

- Look up a parcel by tracking code
- Update a parcel's status
- List all parcels

## Project structure

- main.py: menu and user input
- tracker.py: parcel logic
